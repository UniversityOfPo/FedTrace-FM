# FedTrace_Master_Results — Workbook Specification

## Workbook Status

`Research_Database/FedTrace_Master_Results.xlsx` **exists** and is the
main, human-readable master workbook for this project, with the eight
sheets documented below. It was added directly to this folder (not
generated by any script in this repository) and is not to be recreated
or overwritten by tooling.

This workbook was preceded, earlier in this project, by a CSV-only
version of the same schema: a real `.xlsx` could not be safely
hand-produced through this assistant's available tools at that time (a
`.xlsx` is a ZIP archive of compressed XML parts — binary, not text — and
generating one properly requires a library such as `openpyxl`, which
means running Python code; that session's instructions disallowed both
writing/running code and hand-constructing a binary file). The
specification below and the eight CSVs under
`Research_Database/FedTrace_Master_Results/` were produced as the
sanctioned fallback for that constraint, and remain in place now as the
workbook's **structured source tables** — the authoritative, plain-text
data each sheet is populated from. Each CSV's two-digit filename prefix
matches its sheet's tab order in the workbook (`01_Experiment_Summary.csv`
→ *Experiment Summary*, and so on through `08_Notes.csv` → *Notes*).

Going forward, the CSVs remain where new experiment rows are actually
authored; the workbook is the presentation layer regenerated/
synchronized from them. Future automation (deferred — see `README.md` →
*Update Rules*, "No automation yet") will read experiment outputs to
update the CSVs and then regenerate/synchronize the workbook from those
CSVs, so the two never have to be hand-edited in parallel.

## Sheets

Each subsection below documents one sheet in
`FedTrace_Master_Results.xlsx`, its corresponding CSV source table, and
its exact column schema.

### 1. Experiment Summary
`FedTrace_Master_Results/01_Experiment_Summary.csv`

One row per experiment (mirrors `Experiment_Index.csv`, with additional
result columns). Columns:

`Experiment_ID, Experiment_Name, Type, Git_Commit, Dataset, Model, Seed, Status, Date, Runtime_Seconds, Output_Folder, Checkpoint_Folder, Final_Test_Loss, Final_Test_Top1, Final_Test_Top5, Notes`

### 2. Hyperparameters
`FedTrace_Master_Results/02_Hyperparameters.csv`

One row per experiment. Columns:

`Experiment_ID, Optimizer, Learning_Rate, Momentum, Weight_Decay, Scheduler, Batch_Size, Epochs_Or_Rounds, Local_Epochs, Mixed_Precision, Label_Smoothing, Validation_Fraction`

`Local_Epochs` and `Label_Smoothing` are federated-only / centralized-only
respectively; left blank where not applicable (see `README.md` → *Verified
data only*: blank, never guessed).

### 3. Hardware
`FedTrace_Master_Results/03_Hardware.csv`

One row per experiment. Columns:

`Experiment_ID, GPU_Name, VRAM_GB, Device, OS, Framework, CUDA_Build`

### 4. Federated Results
`FedTrace_Master_Results/04_Federated_Results.csv`

One row per **federated** experiment only. Columns:

`Experiment_ID, Num_Clients, Clients_Per_Round, Minimum_Updates, Communication_Rounds_Configured, Communication_Rounds_Completed, Aggregation_Strategy, Partition_Type, Client_State_Policy, Best_Validation_Round, Best_Validation_Top1, Final_Validation_Loss, Final_Validation_Top1, Final_Validation_Top5`

### 5. Attack Results
`FedTrace_Master_Results/05_Attack_Results.csv`

One row per attack-simulation experiment. **Empty (header only)** as of
this session — no attack experiments exist yet (Phase 4, not started).
Columns (anticipated schema, subject to revision once Phase 4 begins):

`Experiment_ID, Attack_Type, Malicious_Client_Fraction, Baseline_Experiment_ID, Attack_Impact_Top1_Delta, Notes`

### 6. Attribution Results
`FedTrace_Master_Results/06_Attribution_Results.csv`

One row per attribution experiment. **Empty (header only)** as of this
session — no attribution experiments exist yet (Phase 5, not started).
Columns (anticipated schema, subject to revision once Phase 5 begins):

`Experiment_ID, Attribution_Method, Precision, Recall, F1, Baseline_Experiment_ID, Notes`

### 7. Paper Tables
`FedTrace_Master_Results/07_Paper_Tables.csv`

One row per paper table (mirrors `Table_Index.csv`). **Empty (header
only)** as of this session — no paper tables have been authored yet
(Phase 8, not started). Columns:

`Table_ID, Table_Title, Source_Experiment_IDs, Status, Notes`

### 8. Notes
`FedTrace_Master_Results/08_Notes.csv`

Free-form, dated, experiment-linked notes not captured elsewhere.
Columns:

`Date, Experiment_ID, Note`
