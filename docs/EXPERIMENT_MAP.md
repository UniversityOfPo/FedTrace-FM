# Experiment → Paper Table/Figure Map

This maps repository artifacts to the current FedTrace manuscript's tables and figures. Mappings
are stated only where they could be directly confirmed against the repository's own generation
scripts and provenance CSVs; anything not confirmed is marked `UNVERIFIED` rather than guessed.

**Note on numbering:** repository-internal filenames (`table0N_*`, `fig0N_*`) do not always match
the paper's own final table/figure numbers, since some tables/figures were reordered during
writing. The mapping below is by *content*, not by matching filename number to paper number.
